## 📝 Video Description (Copy & Paste All)

```text
CommonScene is a television-first group movie recommendation experience built for the Build, Ship, Shape: Amazon Developer Hackathon 2026.

Every family and friend group knows the "30-minute scroll" — sitting on the couch endlessly browsing streaming menus, arguing over genres, runtimes, and ratings. CommonScene turns group movie selection into a democratic living room game.

📺 HOW IT WORKS:
1. Fire TV Host: The TV launches CommonScene, generating a 4-letter room code and QR join link.
2. Zero-Friction Mobile Join: Viewers join on their phones without app install or account creation (via Mobile PWA).
3. Smart Preferences: Select preferred/excluded genres, feel-good moods, runtime caps, and rating limits — or type natural language preferences.
4. Deterministic Fairness Engine: Ranks movies mathematically: Score(m) = 0.45·Avg + 0.35·Min + 0.20·Coverage - Penalty. Hard constraints are never overridden!
5. Amazon Bedrock AI: Explains recommendations in natural language, grounded strictly in verified score data.
6. Live Living Room Vote: TV showcases top 3 finalists. Everyone votes on their phones, and the TV crowns the winner with fanfare!

⏱️ VIDEO CHAPTERS:
0:00 - The Group Movie Dilemma (30 Mins of Scrolling)
0:19 - Fire TV First Experience (Vega OS 10-Foot UI)
0:39 - Zero-Friction Mobile Participation (React 19 PWA)
0:58 - Deterministic Consensus & Amazon Bedrock AI
1:15 - Realtime Live Voting & Winner Celebration
1:26 - System Architecture & Open Source (Apache-2.0)

🛠️ TECHNOLOGY STACK:
• Television Application: React Native targeting Vega OS runtime with Hermes bytecode
• Mobile Participant Client: React 19, Vite, PWA
• API & Realtime Hub: Node.js, Fastify, WebSockets
• AI Layer: Amazon Bedrock Converse API (Claude 3.5 Sonnet / Amazon Nova Lite)
• Cloud Infrastructure: AWS CDK v2 (Amazon DynamoDB with TTL, S3 + CloudFront OAC, IAM)
• License: 100% Open Source under Apache-2.0
```
